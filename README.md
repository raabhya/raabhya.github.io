# Raabhya Aggarwal · Portfolio

Live site: https://raabhya.github.io

An interactive personal portfolio built with HTML, CSS, JavaScript and three.js.

- index.html: page content
- style.css: styles, dark (Nox) and light (Lumos) themes
- scene.js: three.js particle background that morphs per section
- app.js: interactions (command menu, skills, F1 game, sudoku, bookshelf, writing, contact)
- .jpg files: photos and certificates
